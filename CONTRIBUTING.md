# Contributing to this fork

This is the unofficial [j0ltdevv/hex](https://github.com/j0ltdevv/hex) fork.
Issues, diagnoses, and proposed fixes are welcome at
https://github.com/j0ltdevv/hex/issues/new/choose
They go to this fork's maintainers, not to upstream Anomaly.

Include **redacted** logs only: remove API keys, tokens, transcripts,
vocabulary/screen-term text, paths, and account names. Never ask a reporter to
paste a key or an unredacted log, and never commit a real key or fixture. If the
issue concerns the Groq provider, state whether it was opt-in and whether the
Local fallback was used.

To build Hex yourself, see [`AGENTS.md`](AGENTS.md) and [`docs/`](docs/README.md).
